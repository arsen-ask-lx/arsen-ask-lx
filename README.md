I write code with agents, which means I spend most of my time on the
part nobody films: making sure the machine can prove what it claims.

Every rule I write for an agent has to end in an exit code. A rule that
cannot go red is indistinguishable from a rule that works — and I have
the three weeks of green pipelines to prove it.
